# Financial Analytics Project

A complete Financial Analytics Dashboard using **Python, SQL, Power BI** to analyze Revenue, Expenses, Profit, and Budget Performance.

## 📊 Project Overview
This project analyzes company financial data to track performance across Departments and Regions. 
It includes SQL queries for data analysis, Python for data cleaning, and Power BI for interactive dashboards.

## 🛠 Tools & Technologies
- **SQL** - Data querying and analysis
- **Python** - Data cleaning and analysis
- **Power BI** - Dashboard and Visualization
- **Excel** - Raw dataset
